# 退出停止、保留现场、显式续接

日期：2026-09-11；实施基线 `66bb9f0`。

用户在拒绝专用启动入口及修改 Codex 本体后，提出退出时停止执行但保留记录，重新打开后明确重启任务，并要求“按照这个方案调整落地”。本文件记录该授权对原设计的局部调整；原七份设计文档保留为历史基线，不改写既有实验事实。

## 行为合同

1. 用户继续通过普通 `codex` 使用原主会话。只使用正常工具、Skill/Hook 与本项目 Go 工具；不更改 Codex 本体、安装入口、账号或权限，不使用 MCP 或伪造回调输入。
2. 正常退出时停止本次会话拥有的执行，保留任务记录、已持久化进展、工作目录和待处理结果。强制退出不能假设 SessionEnd 执行；必须实测停止行为，恢复前对账旧执行所有权。
3. 用户通过原生方式恢复**原 thread**，再明确发起继续。打开会话本身不等于恢复执行的请求。新主会话不按 cwd、最近活跃或名称自动认领旧任务。
4. 续接创建新的执行 segment，沿用同一 task、任务版本和已有持久产物。普通退出中断不属于业务失败重试；不因续接清零预算或已完成进展。
5. 只有确认旧执行已结束或无法继续写入，并取得该任务独占所有权后，才启动新 segment。旧状态写着 running 不是存活证据；PID 消失也不是通用执行树停止证据。无法确认时保留现场并拒绝重复启动。
6. 已完成步骤与结果只能被认可一次。完成后重复继续不得重做；持久进度与产物提交之间的中断必须可对账。
7. 续接依靠保存的记录、文件，以及各执行 CLI 经验证的原生 resume 能力。进程内存、旧工具 future 或任意命令的机器指令位置不在恢复保证内。此次不声称 Claude/AGY/Grok adapter 已实现。

## 最小实现与责任

`tools/g0-return-lab/` 增加独立的 retained 子命令，保持旧合成 Host/ACK 的接口与实验可重放。此次只用有界固定步骤验证持久中断与续接，不实现生产调度器、数据库、任意命令执行、真实 CLI adapter 或安装器。

| 责任 | Agent / 独立范围 |
|---|---|
| 合同、整合、最终判定 | 主 Agent；主 worktree 的本合同、总计划与收尾报告 |
| Go 合成生命周期与 TDD | retained_host_impl；独立 host worktree 的 tools/g0-return-lab 与 host 验证记录 |
| 原生 CLI 运行及证据 | native_return_runner；独立 native worktree 的本任务 scripts 与 native-* 记录 |
| 实现与原生证据复核 | 未参与实现的 reviewer；只读，逐项给出范围和缺口 |

实现方向：前台合成进程全生命周期持有稳定 OS 文件锁，使用明确 task/owner/revision/segment 及持久检查点。正常信号退出记录 interrupted；SIGKILL 遗留状态在显式 resume 取得同一锁后对账。合成进程没有后代，不把该锁解释成任意第三方 CLI 执行树的永久容器。

## 验证与完成判据

- 有意义的失败测试先行；真实子进程验证正常信号、SIGKILL、并发续接、旧版本/segment、已完成重复续接和文件损坏。完成原模块 test/race/vet/build 及独立复核。
- 原生 macOS 正常退出、精确恢复、明确继续基础场景 3 次；另做本任务 TUI 强杀样本。保持本地观察 10 秒、模型处理 120 秒，不调整窗口把超时算成功。
- 真实主控关闭后应停止合成执行，保留未完成进展；普通原会话恢复后无新执行，收到真实继续请求后才调用续接；前后步骤无重复。
- 所有原生进程归属使用本任务记录的 PID/出生身份/thread 核验；不得操作主会话或其他人的既有运行实例。
- 任何原生终止或恢复失败均先保留证据并做有界替代实验。不得把 Go 本地夹具通过等同于原生或完整 G0 通过。
