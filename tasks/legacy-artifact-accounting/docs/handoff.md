# Schema22 handoff

Schema22 creates immutable data-only legacy claims. They retain the original declaration and raw allowance, but never create a managed reservation, ref, intake, or filesystem authority. Runtime records freeze the legacy raw classification; report and progress migration split raw only from their pre-existing accounting.

Focused evidence is in `data/receipt.json`. Large interrupted ordinary JSON streams remain local evidence and are deliberately not committed. ROOT owns final full Store ordinary/race/vet after this frozen snapshot.
