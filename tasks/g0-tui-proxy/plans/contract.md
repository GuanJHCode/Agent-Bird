# 受控 TUI 代理与附着实验

2026-09-12，基线 f576230。用户明确允许此前提出的一次受控 TUI 通信代理实验。此授权仅覆盖本任务测试实例，解除原 G0 规格和 pending-resolution 合同对该实验的“不代理原生 TUI 通信”限制；原七份文档保留历史基线。

- 普通 `codex` 入口，不修改 Codex 本体，不增加用户启动命令。不安装 LaunchAgent、全局常驻服务或修改全局配置。测试模型固定 Luna/medium；先用无需模型的原生操作取得通信证据，确需模型时遵守独立 120 秒窗口。
- 仅当默认 socket 未被占用时，本任务临时代理绑定该路径；所有客户端各自一对一连接同一个自有原生 backend 的私有 UDS，不复用一个 stdio 通道。已有服务或陌生连接不接管、不清理。
- 转发真实握手及字节，不伪造用户输入、工具结果、原生响应或历史。观察器只保存白名单身份/方法/请求响应/连接 epoch/顺序/断连字段；正文、凭据和完整 raw transcript 不落盘。无法完整解析或出现缺项时，附着资格失效，不以最近请求猜测当前会话。
- 显式证明 TUI PID/birth/executable → frontend connection → backend connection/service 的链。原服务看到的是代理 peer，必须保存两段身份，不能冒充 OS peer 身份未变化。
- 实验验证初始附着、同 TUI 的原生切换、断连失效；按固定源码给出实际可执行的操作序列。附着推断不得读取测试驱动器自报的 selected/root 标签；测试动作及独立观测只用于验收比较。无法证明的分支保持 unknown。
- 本地操作窗口 10 秒；只操作自有进程/端点，PID、创建身份与 socket inode 匹配后才清理。退出停止执行、保留记录、显式继续的既有目标不缩小。新代理身份链尚未通过前不借用旧 standalone helper 的直接服务绑定去发送回调。
- subagent 在各自 worktree 实现 transport、观察及运行采集；主会话串行整合，独立审查后下发这一受控实验。离线通过不算原生验收，原生部分通过也不算完整 G0；G1–G4 仍等待完整 G0。

## 后继正常退出分支

05 已取得初始 candidate 与独立 `/status` 一致、完整轨迹及零 `turn/start` 的证据；强制断连后新连接尝试恢复空线程返回失败，尚未通过切换及正常退出。本轮事实保留。后继实验增加显式 `normal_quit` 结束模式：先验证初始与 `/clear` 后身份，再由正常 `/quit` 触发真实 EOF，要求退出码 0、旧 epoch 失效及自有资源清理。它不调用主动 disconnect，也不宣称强制断连恢复已通过。默认强制断连模式继续保留。两种结束模式分别记录，不互相替代验收结果。
