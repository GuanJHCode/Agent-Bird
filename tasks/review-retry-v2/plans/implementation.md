## ROOT contract ruling (2026-10-08)

Actual Host contract takes precedence over the initial synthetic terminal assumptions. `host.go` preserves the physical worker exit: successful worker exit 0 can still yield candidate_review_invalid when the review structured schema fails. v2 accepts matching nonnegative actual exit codes, including 0, only after authenticated v2 diagnostic, complete unique lifecycle, readonly-review grant and explicit owner authority. Negative exits stay unsupported. Legacy unversioned diagnostics retain the previous positive-exit rule.

Failed.PayloadHash equals the authenticated diagnostic SHA256. Exited.Artifact equals the same diagnostic ref, while Exited.PayloadHash must equal hashText("exited:"+SegmentID), the existing actual Host lifecycle marker. Do not change `host.go` or fabricate a different Wait result. Prepared has nil Process; Spawned/Running/Failed/Exited carry the same identity. Session, if present, is emitted after Running and before Failed, with same process/tuple and same session identity as the Failed terminal event (`protocol.go` installs observer after Running and reports its authoritative session once).

Controlled Host tests must pass actual emitted events and artifacts into Store and continue through QueueRetry and ClaimReady. No native Provider or Git workspace end-to-end acceptance is claimed by the controlled worker tests.
