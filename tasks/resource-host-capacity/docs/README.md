# Four-source Host capacity runner
The frozen runner copies candidate/controller/runner/thresholds from no-follow FDs
into a private 0700 directory. Its execution path remains fail-closed until ROOT
approves the four-origin admission implementation: it must prove nine live product
actors, 2 running plus 2 ready, fifth typed admission_deferred with unchanged
inventory, a 31-sample 128MiB window, then public collect/accept/ACK and natural
Wait0 cleanup. No candidate was started during preparation.
