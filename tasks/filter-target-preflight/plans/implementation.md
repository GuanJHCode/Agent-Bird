## Primitive contract

Add InspectFilteredTarget and an original live observation owner whose Verify and Close cannot be reconstructed from a wire receipt. Require target Worktree exactly source.repoRoot/accepted.RepoRoot, canonical path, refs/heads named ref and exact accepted.BaseOID; candidate remains direct child through checkFilteredCandidateRef. Bind Broker's original StreamBinding to the request, same manifest and accepted filter evidence; no new files or worktrees are created in the target or Git metadata.

Read target symbolic HEAD/ref/base, HEAD tree and raw ls-files index stage/flags through the existing pinned filter Git context, with exact original Git Wait/tree journaling. Never run status/diff checkout conversion, merge, update-ref, read-tree, write-tree, reset, stash or update-index on target. Reject nonzero stages, skip-worktree/assume-unchanged flags, sparse metadata and in-progress operations. Pin the actual index's identity and contents; revalidate it and operation-marker absence after all callbacks. Existing source/config/Git/tool/attrs/backlink anchors must continue to verify.

Use the bounded base Git tree as the only expected target inventory. Acquire root/parent descriptors without following symlinks and without chmod/write. Enumerate the complete target from held descriptors; only the verified root .git marker is excluded. Require every regular tracked path and required directory, no extra untracked/ignored entry, no symlink/special file/case alias/hardlinked file. Bounds remain 4096 entries, 256KiB path bytes, 512 bytes/path, 16MiB/file and 256MiB total rendered bytes. Directory ownership and file identities must be verified, but observing an existing target confers no cleanup ownership.

For nonfiltered paths, compare actual bytes/hash and executable mode with raw base blob. For filtered paths, stream base B into original slot0, smudge to slot1, clean back to slot2; require exact roundtrip B and actual target R hash/size/mode. Reuse bounded raw tree/blob/attribute helpers and Broker transforms; no temporary target copy or fourth stream file. Keep the accepted candidate's original private ref/source checks independent of the base target check. Recheck original streams binding throughout.

Return a distinct bounded FilteredTargetObservationV1: target path/ref/base, root/common identities, base/index tree or equivalent canonical index digest, raw index identity/hash, candidate OID/tree/receipt binding, ordered inputs, manifest/source-context digest, bounded inventory/collision digest and per-filter B/R evidence. This is observation only, never CandidateDelivery.Target or ReviewBinding. Record through a dedicated RecordFilteredTargetObservation journal method after all preconditions; deep-clone any exported DTO. Immediately reverify target identity/HEAD/ref/index/complete content inventory/source/private-ref after the journal callback. Live Verify uses original held descriptors and journal, not a caller replacement. Close only releases this observer's handles; Broker ownership and cleanup stay with original Host.

## Minimal acceptance and later mutation boundary

Positive preflight must preserve target ref/HEAD/index raw bytes and every target file byte/mode. Assert original Git/filter Wait/tree and normal original Broker cleanup. In the same fixture, journal callback changing a tracked target must prevent receipt return, and target drift after successful publication must fail live Verify. Pure parser/shape guards cover stage/flags/ref/manifest/binding/collision/bounds; reuse existing primitive/cold-journal/filter-ref evidence where unchanged. Independent review plus focused race/build/vet, not broad repeat suites.

This stage never records IntegrationAttempt/integration_authorization and never opens public integrate admission. Final mutation must still use the repository protocol's original tracked git merge --ff-only --no-autostash --no-overwrite-ignore, honoring normal hooks/signing. A future controlled filter bridge must keep Git and Broker lifecycle/journals bound; read-tree + overwrite-copy + update-ref, disabling hooks/signing or silently populating old zero-Target review are not acceptable shortcuts.
