# 支持范围

| 功能 | 状态 |
|---|---|
| Codex owner 绑定、任务派发、collect/ACK/accept | 已实现 |
| 多任务、依赖 DAG、默认全局并发 2 | 已实现 |
| 按会话开启/关闭 Provider | 已实现；关闭等待执行树退出确认 |
| 代码修改的强制隔离与候选测试/审查/集成 | 四种 worker 共用托管流程；Claude/AGY 支持原生结构化审查；Grok 支持有界完整快照审查；Codex 使用轻量读改执行 |
| Claude/Grok/AGY 主脑 | 显式 controller 启动入口；按托管进程归属，不冒充原生会话 ID |
| 会话模型、保存默认、单次覆盖 | 已实现；由实际 CLI 能力决定可用模型 |
| Grok | 保留 1.0.34，增加 1.0.40 的协议兼容与能力门禁；1.0.34 只读、隔离编码/冻结和快照审查已有真实验收，1.0.40 尚无成功的真实模型验收；需显式任务会话目录写授权 |
| AGY | 1.2.5/1.2.7 按任务能力检查；1.2.5 通过一次原生隔离编码及候选冻结；1.2.7 尚未完成只读模型验收，编码/终端工具尚无原生验收 |
| Codex worker（本开发分支） | 固定 0.154.0 + `gpt-5.5` 通过一次真实自主读改、候选冻结及主脑测试；需要 `codex_read_edit_worker_v1`；命令和测试由主脑执行，无 Docker 依赖；本地并存运行时已包含，默认插件/协调器未切换，未发布新安装包 |
| 原生会话 resume | typed profile 未验证，保持拒绝 |
| 自动加预算/自动替换失败任务 | 不支持 |

Grok 只读内置工具限制为 read_file/list_dir/grep；编码增加文件编辑工具，禁用原生子任务和 web search，并传递 MCP 拒绝规则；真实 MCP 负向拒绝尚未完成原生验收。其 artifact 包含公开 assistant 文本，可能含过程说明，不能把最终回答匹配当成整个 artifact 精确匹配。

版本兼容采用增量方式：Grok 已覆盖的构建为 `grok 1.0.34 (3736acbc8658)` 和 `grok 1.0.40 (eb1a2256660d)`，共用原 `grok-streaming-json-v1` 协议，不改写旧 lock。两版原生 help 相同且公共 probe 均通过；受控测试覆盖只读、结构化审查和托管编码请求。未知 Grok 构建或缺少任务所需安全参数仍拒绝，不以宽泛版本范围承诺支持。AGY 1.2.7 公共 probe 已通过；历史 1.2.5 的能力契约保留回归覆盖。

`profile_supported=true` 仅代表适配能力，不是二进制信任、会话写入或模型预算授权。首次使用和摘要变化仍按原流程确认指纹；安装新版 Agent Bird 不升级 Provider CLI，也不迁移其配置、历史和旧任务。任意旧版本、未列出的构建以及新版本的真实业务闭环不由这些检查证明。

Codex worker 仅开放有界代码读取和原生 `apply_patch`，禁止 shell/子进程、web、MCP 和递归委派。真实编码验收用时 17.43 秒，四项主脑断言通过，确认进程组退出、凭据别名清理及原仓未改。原生增删改移、退出与内核拒绝另有无模型验收；真实模型结构化审查、完整的其他主脑到集成链路、任意版本/模型组合仍未验收。源码变更不会自动更新现有安装或运行中的协调器。

本仓库的测试使用合成 fixture 和本地受控子进程。多 Provider 的真实模型并发、任意版本/模型组合和无监督长任务不由这些测试证明。真实 Provider 测试默认 opt-in，运行会消耗对应账号额度。

候选开发拒绝 Git LFS/filter、自定义 hooks 等执行扩展。权限不足或输入不明确时明确阻塞，不自动修改用户全局 Git 或 Provider 配置。

Grok 候选审查由 Host 提供完整 base/candidate Git 文本树，限制为 64 个文件、合计 128 KiB 内容、256 KiB JSON；超限、二进制、符号链接或 LFS 会阻止调用，不截断后继续。认证预检仅调用已锁定 CLI 的非生成 `models`，允许原生客户端续期登录；worker 沙箱不变。AGY 真实审查通过文件读取和错误识别；Grok 真实审查通过快照输入和错误识别。完整 Host 审查到集成另有受控进程回归，不能冒充所有真实模型的端到端验收。
